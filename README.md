
# Hi, I'm Mahdi

## About Me

I'm driven by mastery. I fell in love with design and code in 2019, not just as skills, but as crafts worth perfecting. Since then, I've built web and mobile software across the modern tech stack, constantly exploring new tools and better ways to build.

Whether I'm engineering software or training calisthenics, my mindset stays the same: **discipline, consistency, and mastery**. I apply that philosophy to everything I build, from well-structured databases to polished, accessible interfaces.

I also bring a deep interest in psychology to product design, using it to create experiences that feel clear, natural, and intuitive for the people using them.

Oh, and I'm a magician too. No smoke and mirrors in the codebase ;)
